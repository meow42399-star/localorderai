# LocalOrderAI

تطبيق أندرويد للاتصال التلقائي بقائمة أرقام (كل سطر رقم)، مع تسجيل نتيجة كل مكالمة
(أنا قفلت / هو قفل / مشغول / رفض / مفيش رد)، وزراير المكبر والميوت.

- لازم يتفعّل كتطبيق الاتصال الافتراضي (Default Dialer).
- كل push على `main` بيبني APK موقّع وينشره كـ Release جديد (`v2.0.N`)، والتطبيق بينبّهك للتحديث.
- التوقيع بيتم من GitHub Secrets (`KEYSTORE_BASE64` و`KEYSTORE_PASSWORD` و`KEY_ALIAS` و`KEY_PASSWORD`) — متغيّرهمش عشان التحديثات تفضل شغالة.

## تقارير المشاكل

- من التطبيق: زرار **ابعت تقرير المشكلة** بيفتح Issue جاهزة على GitHub (الأرقام بتتخبّى، آخر 3 أرقام بس)، أو **انسخ التقرير** للحافظة.
- أي crash بيتسجّل لوحده ويظهر عرض إرسال في المرة الجاية.
- القراءة (من غير توكين، الريبو عام): `https://github.com/meow42399-star/localorderai/issues`
  أو `curl https://api.github.com/repos/meow42399-star/localorderai/issues`

## المكبر والميوت

- **الوضع الكامل** (التطبيق هو الاتصال الافتراضي): المكبر والميوت عن طريق InCallService، ومعاه "مين قفل".
- **الوضع البسيط** (من غير Default Dialer):
  - المكبر: بيتحدد **وقت طلب الاتصال نفسه**: كل مكالمة بتتطلب عن طريق `TelecomManager.placeCall` ومعاها `EXTRA_START_CALL_WITH_SPEAKERPHONE = true`، ونظام الاتصال (Telecom) هو اللي بيبدأها على السماعة. ده نفس أسلوب التطبيق المرجعي (دالة `makeRegularCall`)، ومحتاج إعداد المكبر شغّال بس. تغيير مسار الصوت وسط المكالمة من تطبيق عادي بيرفضه النظام على أندرويد 12+ (اتجرّب وفشل على A26/Android 16)، فمش بنحاول. زرار "المكبر الآن" بيبدّل الإعداد والتغيير بيتطبق من المكالمة الجاية. **وسط المكالمة (الوضع البسيط):** الزرار بيدوس على زرار المكبر في إشعار المكالمة لو موجود، عن طريق خدمة **الوصول للإشعارات** (`CallNotificationService`) اللي بتهتم بإشعارات المكالمات بس. لتفعيلها: زرار "تفعيل الوصول للإشعارات" في التطبيق، ولو الخيار رمادي: إعدادات التطبيق ← ⋮ ← السماح بالإعدادات المقيّدة. أزرار إشعار المكالمة بتتسجّل في تقرير المشكلة (`call notification: ... actions=[...]`).
  - الميوت: `setMode(IN_CALL)` ثم `setMicrophoneMute` بعد 200ms.
